# Michango Manager 🏠

Mfumo wa kidijitali wa usimamizi wa michango ya matukio — harusi, misiba na sherehe.

Project ya kujifunzia ya **Safari ya Software Development** — series ya TEHAMA TDC Global inayojenga real-life application kutoka idea hadi deployment, session kwa session.

## Problem Statement (Commit Zero)

> Kamati za matukio (harusi, misiba na sherehe) zinapata shida ya kusimamia michango kwa sababu hazina mfumo maalum — zinategemea madaftari, Excel na kumbukumbu za vichwani. Hii inasababisha taarifa kupotea, kutokujua kwa wakati nani amechangia na nani bado, na ugumu wa kutoa ripoti sahihi. Zaidi ya hayo, michango isiyo ya fedha — vitu, huduma na nguvu kazi — mara nyingi hairekodiwi kabisa, na mchango wa watu hao husahaulika wanapofikwa na shida zao wenyewe. Tunajenga **Michango Manager**, mfumo wa kidijitali utakaowezesha kamati kusajili wachangiaji, kurekodi ahadi na michango ya fedha na isiyo ya fedha, na kupata ripoti sahihi wakati wowote.

Sentensi hizi ndiyo msingi wa kila kitu kwenye repo hii.

## Muundo wa Repo

- `docs/` — nyaraka zote za project: tatizo, requirements, design, setup (zinakua kila session)
- `app/` — code ya application: `index.html` (muundo), `css/` (muonekano), `js/` (akili), `assets/` (picha na files)

## Kuanza (kwa wanafunzi)

```bash
git clone https://github.com/[org]/mchango-manager.git
```

Kisha fungua folder kwenye VS Code, na fungua `app/index.html` kwenye browser. Kabla ya kila session: `git pull` kupata mabadiliko mapya.
